MODULE 04 / FINANCIAL RESILIENCE

如何防范“戴维斯双杀”

股票“双杀”指盈利与市场估值倍数同时下降。LENDX 并不直接对应每股盈利，但也可能发生相似的业务—代币价格负反馈：收入减少、代币信心下滑，激励与运营资金进一步承压。

四道风险隔离防线

① 三类资金分账、分主体、分权限平台经营现金｜贷款资产池及投资人资金｜LENDX 激励与国库。不得使用池资产托价或偿付平台运营。
② 激励使用三重限制净服务收入预算上限、代币数量上限、可用现金覆盖上限；价格下跌不自动扩大流通供给。
③ 服务权益按实际成本定价会员、API 和 Agent 任务包按有效报价和预算兑现；新兑换率可调整，但必须尊重已确认承诺。
④ 对减值与赎回做周期压力测试独立模拟坏账上升、回款延迟、MXN 汇率波动、投资人集中赎回；现金不足时排队。
