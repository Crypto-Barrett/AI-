新增：三项优先权益

RIGHT 01 · 按量付费

Agent 任务服务额度

合作机构或获授权 Agent 消耗 LENDX 兑换指定任务包，例如材料核验、回款匹配、差异解释、数据质量检查。

规则：报价与任务数量公开；按确认的额度扣减；失败可按约定退回未消费额度；有效期、单户和月度总预算设上限。
优先级 P0
RIGHT 02 · 会员与折扣

机构服务会员

机构获得更多协作席位、API 调用配额和平台自有服务费优惠，不触及利率审批和资金方授信决定。

规则：会员期限、套餐内容、折扣范围和金额上限明确；锁定代币仅用于会员资格，不保证收益；未提供服务按条款处理。
优先级 P0
RIGHT 03 · 数据增值

资产监控与分析报告

按合同覆盖的资产池和贷款量，提供回款偏差告警、组合风险监控、对账报告和可下载分析结果。

规则：按报告/监控对象/时间窗口计量；按权限提供脱敏数据；超额增购、到期失效，未完成报告支持补发或按约定退款。
优先级 P0

MODULE 04 / FINANCIAL RESILIENCE

如何防范“戴维斯双杀”

股票“双杀”指盈利与市场估值倍数同时下降。LENDX 并不直接对应每股盈利，但也可能发生相似的业务—代币价格负反馈：收入减少、代币信心下滑，激励与运营资金进一步承压。

四道风险隔离防线

① 三类资金分账、分主体、分权限平台经营现金｜贷款资产池及投资人资金｜LENDX 激励与国库。不得使用池资产托价或偿付平台运营。
② 激励使用三重限制净服务收入预算上限、代币数量上限、可用现金覆盖上限；价格下跌不自动扩大流通供给。
③ 服务权益按实际成本定价会员、API 和 Agent 任务包按有效报价和预算兑现；新兑换率可调整，但必须尊重已确认承诺。
④ 对减值与赎回做周期压力测试独立模拟坏账上升、回款延迟、MXN 汇率波动、投资人集中赎回；现金不足时排队。
